# PLC Basics – Industrial Automation

This repository contains my hands-on learning and practical experiments with **Programmable Logic Controllers (PLCs)** using **Delta PLC and WPLSoft**.

The objective of this work is to understand the fundamentals of industrial automation through practical PLC programming, ladder logic development, and basic control system implementation.

## Topics Covered

* Introduction to Programmable Logic Controllers (PLCs).
* PLC architecture and working principles.
* Understanding Digital Inputs and Outputs.
* PLC Scan Cycle and its operation.
* Ladder Logic Programming.
* NO (Normally Open) and NC (Normally Closed) contacts.
* Output coils and internal relays.
* Timer and Counter instructions.
* Motor Start/Stop control logic.
* Basic industrial automation applications.

## Software & Hardware Used

* **PLC:** Delta PLC
* **Programming Software:** WPLSoft
* **Programming Language:** Ladder Logic (LAD)

## Practical Experiments

1. Basic PLC programming and hardware configuration.
2. Digital input and output operations.
3. Motor Start/Stop control using push buttons.
4. Timer-based control operations.
5. Counter-based operations.
6. Interlocking logic.
7. Basic automation sequences using ladder diagrams.

## Learning Outcomes

* Gained practical exposure to PLC programming using Delta PLC.
* Developed an understanding of ladder logic and industrial control systems.
* Learned to implement basic automation sequences.
* Understood how PLCs interact with field devices through digital inputs and outputs.
* Gained familiarity with WPLSoft for developing, testing, and debugging PLC programs.

## Objective

To build a strong foundation in industrial automation and control systems through hands-on PLC programming and practical implementation.
